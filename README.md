# FireRed Gen9 Randomizer Workspace

Privater Projekt-Workspace für einen Pokémon FireRed Gen9 Custom Hack mit späterer Kompatibilität zu:

- Universal Pokémon Randomizer FVX
- Complete FireRed Upgrade / Dynamic Pokémon Expansion
- Hex Maniac Advance
- BizHawk
- Ironmon Tracker
- Codex / ChatGPT-gestütztem Entwicklungsworkflow

## Ziel

Dieses Repository ist die Source of Truth für Projektstruktur, Dokumentation, Entscheidungen, Tool-Manifeste, Tests und Scripts.

Es enthält keine ROMs, Saves, Builds oder urheberrechtlich relevanten Dateien.

## Aktueller Stand

Phase: Initialer Workspace-Aufbau

Nächster Fokus:

1. Dokumentationsbasis füllen
2. Tool- und Quellenmanifest erstellen
3. Codex-Regeln definieren
4. Bootstrap-Script für reproduzierbaren Workspace vorbereiten
5. Danach externe Repos gezielt klonen und pinnen

## Wichtige Dateien

- `AGENTS.md` – Regeln für Codex und andere Coding Agents
- `01_docs/PROJECT_BRIEF.md` – Projektüberblick
- `01_docs/SESSION_STATE.md` – aktueller Stand
- `01_docs/NEXT_STEPS.md` – nächste Arbeitsschritte
