# M-013 — NatDex Premier Ball purchase bonus

**Status:** **IMPLEMENTED / INTEGRATED; targeted runtime report is a
CONFIRMED USER-SUPPLIED REVISION-BOUND RUNTIME PASS.**

M-013 is the bounded source-backed Premier Ball behavior identified by M-012.
For a successful purchase of an item in the ball pocket, the integrated CFRU
callback awards `floor(quantity / 10)` Premier Balls, clamps the award to the
available capacity, awards it once, and preserves the existing non-ball reward
policy. It does not change item IDs, prices, shop inventories, DPE data or
UPR-FVX writers.
