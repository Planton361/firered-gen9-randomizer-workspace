## Helper hazards repaired before data promotion

| Hazard | New failure boundary / check |
| --- | --- |
| Several species/forms write one table | Group by actual target, compare all ordered expectations before any write; deduplicate identical replacements |
| Empty literal form data overwrites base table | Empty/missing literal level-up records block; no guessed inheritance or fallback |
| Cross-generation shared consumers ignored | Always audit the full pilot; partial-generation writes refused |
| A local consumer is absent/ignored/ambiguous | Block the shared target rather than choosing another consumer's data |
| SPECIES_* update keys do not match normalized pointers | Normalize at writer boundary; missing targets raise instead of silently skipping |
| Inline `LEVEL_UP_END};` declarations missed | Parse inline terminators, comments, duplicate/unbound pointers and complete block boundaries; preserve original suffix |
| Repeated length-changing replacements corrupt adjacent tables | Prevalidate and coalesce, then replace each original span once in reverse order; exact whole-file replay |
| Ignored pattern aliases silently bypassed | Pattern matching now participates in resolution, with blocked/ignored precedence |
| First matching move/ability alias wins | Ambiguous alias targets block; unsupported abilities never emit a candidate assignment |
| Missing early-level rows/bounds | Valid nonzero u16 move IDs, sorted levels 0–100, maximum 50 rows, and an eligible L1 move required for writes |
| Unrecorded external HEAD or config drift | Exact commit, four file hashes, alias hash and canonical input-file checks are mandatory |
| Unrequested DPE writes | Only active CFRU learnsets writable; any actual safe base diff requires a separate bounded DPE candidate |

The parser is deliberately not a general Showdown simulator. Existing policy
is retained: for each move take the levels from its latest available generation,
retaining older-generation-only moves. Equal-level ordering follows source
property order. Pure ordering differences are blocked because the CFRU initial
moveset uses the eligible prefix's last four rows. This is **not** strict SV
move availability, nor a claim to reproduce Showdown form-inheritance behavior.

The four source files and aliases are hash-locked. Future policy or parser
changes require a new reviewed lock/helper revision; inventory metadata records
all four participating helper-file SHA-256 values. No external HEAD is trusted.

## Low-level invariant and severity

For each active target, the inventory records row bounds, first move level,
the actual eligible-prefix last four moves at L1, all consumers, and whether
reference legality is resolved. L1 is a conservative check stronger than normal
wild encounter levels; it does not assert every form is encounterable. A valid
status move counts as a move path; an empty/NONE slot does not. No fallback is
invented. Levels 1–100 are also checked through the actual initial-move function
in the component's sanitized C host harness.

Candidate: 1,097/1,105 targets pass structural L1 bounds/nonemptiness; 915 have
full literal-reference agreement. The other 182 nonempty targets remain
unresolved for source legality; they are not promoted to a data PASS.

Seven non-sentinel targets fail L1: Pikachu, Rotom, Necrozma, Zacian, Zamazenta,
Dialga (first 50) and Zygarde (first 80). They cover 38 source species/form
bindings. The intentional empty sentinel has another 27 bindings. Sandshrew
and Litleo (previous first level 5) are repaired, reducing failing targets by
two. These are **S1-risk source gates if affected species can enter low-level
encounters**, not runtime-only acceptance notes. Zarude-Dada's null pointer is
another S1 crash risk if selected. Exact encounter/profile reachability remains
unvalidated; this pass does not change a randomizer species pool or the engine.
